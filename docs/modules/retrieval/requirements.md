# 查询定位模块需求

## 目标

让上游业务系统输入一个单词或短语后，拿到真实出现位置与可展示的上下文。

## 必达能力

- 支持单词查询
- 支持短语查询
- 返回文档名、页码、句子或题目文本
- 支持文档名、学科、年级、年份过滤
- 支持分页
- 支持结果按相关度排序

## 业务规则

- 短语查询必须返回完整短语命中，不允许拆碎
- 大小写归一和词形归一由本服务负责
- 只返回已就绪且未删除文档
- 无命中返回空列表，不视为错误
- 结果必须可回指到原文中的句子或题目

## 结果语义

- 教材 / 讲义类：优先返回句子
- 试卷类：优先返回题目文本
- 命中记录至少包含：
  - 文档名
  - 页码
  - 关联文本
  - 锚点位置

## 非目标

- 不提供聊天式问答
- 不提供释义、翻译、改写
- 不承担上游业务的展示逻辑
