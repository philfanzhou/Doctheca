# 语义召回设计

## 目标

在精确检索之外补充“意思相近”的句子或题目，但不替代精确检索主能力。

## 技术选择

- 向量库：Qdrant
- Embedding：SiliconFlow Embedding API
- 推荐模型：`BAAI/bge-large-en-v1.5`

## 切分粒度

- 句子级
- 题目级
- 必要时段落级

## 设计原则

- 所有向量条目必须带锚点
- 语义召回结果必须能回指到文档、页码、句子或题目
- 语义召回结果与精确检索结果需要去重合并

## 适用场景

- 查相近表达
- 查意思相近的句子
- 查某个词在不同题型中的变体考法

## 不采用

- 不只保留粗粒度 chunk
- 不把语义召回结果伪装成精确命中
