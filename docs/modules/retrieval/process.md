# 查询定位流程

## 主流程

1. 业务系统准备查询词、过滤条件和分页参数
2. 调用 gRPC 查询接口
3. 系统执行大小写与词形归一
4. 系统执行精确检索，并按请求决定是否补充语义召回
5. 系统对命中结果去重
6. 系统按相关度排序
7. 系统返回命中列表与翻页游标

## 关键规则

- 单词查询与短语查询使用不同匹配策略
- 同一页同一句 / 同一题的重复命中需要合并
- 未就绪文档和已删除文档必须先被过滤掉
- 无命中返回空结果集

## 典型异常

- `query` 为空：返回 `InvalidArgument`
- `query` 超长：返回 `InvalidArgument`
- `page_size` 超过上限：返回 `InvalidArgument`
- OpenSearch 不可用：返回 `Unavailable`
- Qdrant 不可用：返回 `Unavailable`

## 输出语义

- 返回值必须可用于前端高亮
- 返回值必须能还原到句子或题目级锚点
