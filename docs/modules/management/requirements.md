# 文档管理模块需求

## 目标

对已进入系统的文档提供稳定、可解释的管理能力，保证查询过滤、文档生命周期和索引状态一致。

## 覆盖能力

- 分页查看文档列表
- 按标题模糊搜索
- 按学科 / 年级 / 年份 / 状态筛选
- 查看导入状态
- 修改元数据
- 删除文档

## 业务规则

- 文档名与文件哈希是不可变业务标识
- 只有已就绪文档允许修改元数据
- 元数据修改后，检索过滤应立即反映新值
- 删除是硬删除，不可恢复
- 删除后同名和同内容文档都允许重新上传
- 删除后的文档不能再出现在查询结果中

## 非目标

- 不处理上传校验细节
- 不处理查询排序与召回逻辑
- 不引入批量删除作为首版能力
