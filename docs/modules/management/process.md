# 文档管理流程

## 文档列表流程

1. 管理员进入文档列表页
2. 系统按分页参数返回文档列表
3. 管理员可按标题、学科、年级、年份、状态筛选

## 元数据修改流程

1. 管理员选择一份已就绪文档
2. 编辑学科 / 年级 / 年份 / 标签中的至少一项
3. 系统校验：
   - 文档存在
   - 文档状态为已就绪
   - 新值合法
   - 文档名与文件哈希未被修改
4. 系统更新数据库记录
5. 系统同步刷新索引中的过滤字段

## 删除流程

1. 管理员按文档名选择文档
2. 系统查找文档记录
3. 系统物理删除数据库、原始文件、任务记录和索引数据
4. 系统返回删除结果

## 异常分支

- 文档不存在：删除返回幂等成功
- 文档未就绪：元数据修改直接拒绝
- 试图修改文档名或文件哈希：直接拒绝
- 索引清理失败：删除返回失败并允许重试
