# 文档列表查询与筛选（DocumentList）

## 功能名称与一句话概括

**功能名称**：文档列表查询与筛选

**一句话概括**：管理员在管理界面上按学科、年级、年份、状态等条件筛选文档，分页浏览文档列表。

---

## 核心用户故事

**User Story — 管理员视角**

> 作为一名管理员，我希望在管理界面上按学科、年级、年份、状态等条件筛选文档，并分页浏览文档列表，从而快速定位和管理目标文档。

---

## 关键验收条件摘要（可测试）

1. **AC-1：多条件筛选** — 支持按 status/subject/grade/keyword/year 筛选，全部可选，未提供的筛选条件不参与过滤。
2. **AC-2：分页参数修正** — page≤0 修正为 1，size≤0 修正为 20，size>100 修正为 100。
3. **AC-3：领域层返回结构** — 返回 `(List<DocumentModel> Items, int TotalCount)`。
4. **AC-4：Admin 端点返回结构** — JSON 含 items/total/page/pageSize/totalPages。

---

## 范围外（不做什么）

- **不涉及文档创建、修改、删除**：本功能只读，不修改任何数据。
- **不实现排序功能**：列表按默认排序返回，不提供自定义排序参数。
- **不实现导出功能**：不支持将文档列表导出为 Excel/CSV。
- **不涉及权限控制**：Admin 端点默认管理员可访问，不做细粒度权限校验。
