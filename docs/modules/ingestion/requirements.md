# 文档导入模块需求

## 目标

把英文教材、真题、讲义等文档安全地导入系统，并产出可被查询模块消费的已就绪文档。

## 支持范围

- 支持类型：PDF（含扫描件）、Word、PPT
- 支持来源：管理员 / 运营人员通过 Web 管理界面上传
- 支持结果：生成导入任务，并允许查看导入状态

## 必达能力

- 校验必填元数据：文档名 / 学科 / 年级 / 年份
- 校验学科合法性：当前仅支持英语
- 校验年级合法性：当前仅支持 K-12
- 校验文档名唯一：同名拒绝上传
- 校验文件哈希唯一：同一份文件内容拒绝重复导入
- 校验文件非口令加密 / 非数字加密
- 生成导入任务并异步处理
- 提供导入状态查看能力

## 业务规则

- 上传是“同步受理 + 异步处理”，不是同步导入完成
- 校验失败必须在受理阶段直接拒绝
- 未成功导入的文档不能出现在查询结果中
- 导入成功后，文档状态才进入“已就绪”

## 非目标

- 不由业务系统直接上传
- 不在本模块处理查询、删除、元数据修改
- 不在本模块提供聊天、翻译、释义能力
