# 文档导入流程

## 主流程

1. 管理员在 Web 管理界面选择文件并填写必填元数据
2. 系统执行同步校验
3. 校验通过后创建导入任务并返回任务 ID
4. 后台 Worker 异步执行解析、OCR、建索引
5. 管理员通过状态接口查看任务进度
6. 导入成功后文档进入已就绪状态

## 状态机

```text
pending -> processing -> success
                    \-> failed
```

## 状态说明

- `pending`：任务已创建，尚未开始处理
- `processing`：正在解析、OCR 或建索引
- `success`：导入完成，文档可被查询
- `failed`：导入失败，需查看错误原因

## 异常分支

- 元数据缺失：同步拒绝
- 学科或年级非法：同步拒绝
- 文档名重复：同步拒绝
- 文件哈希重复：同步拒绝
- 文件加密：同步拒绝
- 文件损坏 / 解析失败：进入 `failed`
- OCR 质量过差：进入 `failed` 或记录警告
- 索引失败：进入 `failed`

## 关键约束

- 成功与失败都是终态，不互转
- 未到成功态的文档不可查询
- 失败后应通过重新上传形成新任务，而不是复用旧任务
