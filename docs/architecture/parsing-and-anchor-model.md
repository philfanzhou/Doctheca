# 解析与锚点模型

## 解析输入

- PDF（含扫描件）
- Word
- PPT

## 解析职责

- 抽取文本
- 保留页码、块、行级信息
- 识别句子边界
- 识别题目边界
- 为后续检索产出结构化锚点

## OCR 后处理

- 合并被连字符拆开的单词
- 归并多余空白
- 修正常见 OCR 错字
- 记录低置信度页面警告

## 锚点层级

- 文档
- 页面
- 块
- 句子
- 题目
- 文本偏移

## 关键输出

- `DocumentPage`
- `DocumentSegment`
- `QuestionSegment`
- `DocumentOccurrence`

## 设计原则

- 锚点必须稳定可引用
- 所有检索结果都必须回到句子或题目级
- OCR 不改变锚点模型，只影响文本来源
