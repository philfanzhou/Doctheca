# 存储与索引

## PostgreSQL

用途：

- 文档主数据
- 页面、片段、题目、出现记录
- 导入任务

## SeaweedFS

用途：

- 保存原始文档文件
- 支撑重新解析与原始文件查看

## OpenSearch

用途：

- 精确词检索
- 精确短语检索
- 元数据过滤
- 高亮偏移

## Qdrant

用途：

- 句子级 / 题目级向量存储
- 语义召回
- 与过滤条件组合查询

## 一致性要求

- 导入成功后，数据库、OpenSearch、Qdrant 三者都要可消费
- 删除成功后，三者都要清理对应文档数据
- 元数据修改后，过滤字段要同步刷新
