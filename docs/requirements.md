# DocRetrieval 业务需求文档

> 本文档只描述业务能力，**不涉及任何技术选型、架构、接口协议、存储与实现方式**。
> 业务流程（谁在什么时机做什么、状态如何流转）见 [process.md](./process.md)；
> 怎么做请参考 [spec.md](./spec.md)。

## 1. 业务背景

学生在学习英文教材、做英文真题时，常常需要"按词回原文"：看到一个生词或短语，希望快速知道"它出现在哪份文档的哪一页、所在句或所在题是什么"。

当前没有统一的检索底座，上游多个业务各自为战。本服务提供两套能力：

- **Web 管理界面（本服务自带）**：用于上传 / 删除文档
- **查询接口（暴露给业务系统）**：按单词 / 短语，拿到"在哪份文档的哪一页的哪个句 / 哪道题"

## 2. 服务定位

- 本服务**自带 Web 管理界面**，供管理员或运营人员上传、删除、查看文档导入状态。
- 本服务**对外（给业务系统）仅暴露一个能力**：查询定位。
- 业务系统（上游微服务）只能调用查询接口，不能通过本服务上传 / 删除文档。
- 终端用户（学生 / 教师 / 家长）由上游业务系统服务，不直接访问本服务。

## 3. 能力范围

### 3.1 支持的文档类型

导入操作支持以下文档类型：

| 类型 | 说明 |
|------|------|
| PDF | 包含电子版 PDF 与扫描型 PDF（扫描件走 OCR） |
| Word | `.doc` / `.docx` |
| PPT | `.ppt` / `.pptx` |

### 3.2 本服务自带能力（Web 管理界面）

| 能力 | 用途 | 使用者 |
|------|------|--------|
| 上传文档 | 把一份英文文档（PDF / Word / PPT）送进本服务 | Web 管理界面 |
| 删除文档 | 把一份已导入的文档从检索底座中移除 | Web 管理界面 |
| 查看导入状态 | 跟踪导入任务的进度与结果 | Web 管理界面 |
| 文档列表 | 分页查看已导入文档，支持按文档名模糊搜索 + 学科 / 年级 / 年份 / 状态筛选 | Web 管理界面 |

### 3.3 对外暴露能力（供业务系统调用）

| 能力 | 用途 | 调用方式 |
|------|------|----------|
| 查询定位 | 传入单词 / 短语，得到"文档 + 页码 + 句 / 题"（游标分页，默认最多 100 条） | gRPC |

> 业务系统**只能调用查询定位**，不能上传 / 删除文档。
> 本服务**不提供**聊天、释义、翻译、改写、用户态、权限等能力。这些由其它服务负责。

## 4. 接口说明

### 4.1 上传文档（Web 管理界面）

- **入参**：一份文档文件 + 元数据（必填：教材名 / 学科 / 年级 / 年份；可选：标签等）
- **返回**：导入任务 ID + 状态跟踪入口
- **行为**：
  - 校验元数据必填项
  - 校验教材名是否已存在（重名拒绝上传）
  - 解析文档内容
  - 抽取页码、段落、句子、题目边界
  - 建立可被"查询接口"使用的索引
- **支持格式**：`PDF`（含扫描件）/ `Word` / `PPT`（详见 §3.1）

### 4.2 删除文档（Web 管理界面）

- **入参**：文档标识（导入时使用的文档名）
- **返回**：成功 / 失败 + 业务可读的失败原因
- **行为**：
  - 按"文档名"找到对应的文档
  - 标记为"已删除"（软删除）
  - 从检索索引中移除（不可再被查询）
  - 不会清空原始文件与历史任务记录
- **支持状态**：任何状态下的文档都可被删除（导入中 / 已就绪 / 已失败）

### 4.3 查询定位接口（gRPC，供业务系统调用）

- **入参**：
  - `query`：要查的**单词**或**短语**
  - 可选过滤：教材名 / 学科 / 年级 / 年份 等
  - 分页：`page_size`（可选，默认 50，最大 100）+ `page_token`（游标）
- **返回**：命中列表 + `next_page_token`（如有更多结果）+ `total_count`，每条命中包含：
  - **文档名**：该命中来自哪份文档
  - **页码**：出现在第几页
  - **关联文本**：该词 / 短语所在的**句子**（普通文档）或**题目**（试卷类文档）
- **行为**：
  - 支持单词查询、短语查询
  - 短语查询必须返回**完整短语命中**，不得拆碎
  - 大小写、词形做归一化（具体规则由规格说明约束）
  - 返回结果按相关度排序
  - 使用游标分页，`next_page_token` 为空时表示已到最后一页

## 5. 查询结果示意

> 以下仅为业务字段示意，**不指定具体协议 / 字段名**（由 [spec.md](./spec.md) 决定）。

一次查询返回多条命中，每条命中至少含 3 个业务字段：

| 字段 | 业务含义 |
|------|----------|
| 文档名 | 该命中所在文档的名称 |
| 页码 | 该命中所在页 |
| 关联文本 | 该词 / 短语所在的**句子**（教材类）或**题目文本**（试卷类） |

示例：业务系统调用"查询 'encourage'"，可能拿到以下命中（简化）：

| 文档名 | 页码 | 关联文本 |
|--------|------|----------|
| 人教版高中英语必修一 | P23 | "Teachers should encourage students to ask questions." |
| 2023 年高考英语全国卷 I | P5（题 21） | "The author aims to encourage readers to ..." |
| ... | ... | ... |

## 6. 业务验收口径

> 仅"业务视角"，不涉及性能 / 可用率等技术指标（见 [checklist.md](./checklist.md)）。

### 6.1 必达项

- ✅ Web 管理界面能上传 PDF（含扫描件）/ Word / PPT 三类文档
- ✅ Web 管理界面能查看导入任务的状态（成功 / 失败 / 进行中）
- ✅ Web 管理界面能按"文档名"删除一份已导入的文档
- ✅ 业务系统能通过 gRPC 查询接口按"单词"查询，返回该词所在的文档名 + 页码 + 关联文本
- ✅ 业务系统能通过 gRPC 查询接口按"短语"查询，返回包含该完整短语的句 / 题（不拆碎）
- ✅ 试卷类文档查询时，关联文本为"该词所在题目"
- ✅ 教材类文档查询时，关联文本为"该词所在句子"
- ✅ 已被删除的文档在查询结果中不再出现

### 6.2 不在本期范围

- ❌ 中文 / 其它语种（首版仅支持英文）
- ❌ 聊天式问答
- ❌ 单词释义、翻译、词性分析
- ❌ 文档内容改写 / 二次创作
- ❌ 用户账号、权限管理（Web 管理界面的鉴权由基础设施层负责）
- ❌ 业务系统上传 / 删除文档（仅 Web 管理界面可操作）
- ❌ 文档批量删除（首版只支持单文档按"文档名"删除）
- ❌ 删除后恢复 / 撤销
- ❌ 物理清空已删除文档的存储与历史

## 7. 业务约束

| 约束 | 业务含义 |
|------|----------|
| 文档类型 | 至少支持 PDF（含扫描件）/ Word / PPT 三类 |
| 文档语言 | 首版仅支持英文 |
| 规模 | 中规模（一年内数千份文档），单文档可含上千页 |
| 检索语义 | 至少支持"精确词 / 短语"，可选支持"语义相近"召回 |
| 命中可解释 | 每次命中必须能"指到原文所在的句 / 题"，不得只给"可能相关" |
| 文档标识 | Web 管理界面按"教材名"作为业务唯一标识；同名不允许重复上传 |
| 分页上限 | gRPC 查询接口单次返回最大 100 条，默认 50 条 |
| 边界 | 业务系统只能调查询接口；上传 / 删除只能通过 Web 管理界面 |

## 8. 业务术语表

| 术语 | 业务含义 |
|------|----------|
| 文档 | 一份导入本服务的文件（PDF / Word / PPT 等） |
| 文档名 | Web 管理界面按"业务唯一"原则指定的文档名称，是查询过滤与删除的主键 |
| 单词 | 业务系统按"单词"粒度查询时使用的检索单位 |
| 短语 | 由多个单词组成的固定或半固定表达（如 "take notes"） |
| 关联文本 | 命中所在的"句子"（教材类）或"题目文本"（试卷类） |
| 命中 | 一次查询的返回条目，对应"某词 / 短语在文档某处出现" |
| 导入任务 | 把一份文档送入本服务并完成解析 / 建索引的完整流程 |
| 业务系统 | 通过 gRPC 调用本服务查询接口的其它后端微服务 |
| Web 管理界面 | 本服务自带的管理页面，用于上传 / 删除 / 查看导入状态 |
| 终端用户 | 最终使用学习产品的人（学生 / 教师 / 家长等），**不直接访问本服务** |
| 软删除 | 标记为"已删除" + 从检索索引移除，但保留原始数据，可由 Web 管理界面重新发起导入 |

## 9. 与上游需求 / 业务流程的对应

本服务的业务需求来自项目主需求文档 [docs/需求文档-英语错题分析与词汇学习系统.md](../../../requirements-英语错题分析与词汇学习系统.md)，对应主线如下：

| 项目主需求 | 本服务对应能力 | 调用路径 |
|------------|----------------|----------|
| 生词自动提取 | 查询接口（按单词定位原句） | 业务系统 → gRPC 查询 |
| 教材定位 | 查询接口（按教材过滤 + 返回句） | 业务系统 → gRPC 查询 |
| 原句展示 | 查询接口返回的"关联文本" | 业务系统 → gRPC 查询 |
| 真题推送 | 查询接口在试卷类文档上返回"题目" | 业务系统 → gRPC 查询 |
| PDF 导出 | 批量调用查询接口获取"关联文本" | 业务系统 → gRPC 查询 |
| 教材下架 / 错题文档清理 | Web 管理界面删除文档 | Web 管理界面操作 |

> 上游主需求文档中"用户"层面的描述由上游业务系统承接；本服务只承接"按词 / 按短语定位原文"这一底层能力（通过 gRPC 暴露）。

## 10. 业务不变式

下面这些是**业务层面的硬约束**，技术实现不得绕过：

1. **每条命中可指回原文**：返回的 `关联文本` 必须是文档中真实存在的句子 / 题目。
2. **短语查询不拆碎**：返回的命中中，`关联文本` 必须**完整包含**用户传入的短语。
3. **粒度不串台**：教材类返回句，试卷类返回题；不允许在教材上返回"题"，也不允许在试卷上返回"段落"。
4. **未就绪不可查**：未成功导入的文档不能出现在任何查询结果中。
5. **已删除不可查**：被软删除的文档不能出现在任何查询结果中。
6. **状态单调收敛**：导入任务一旦成功，不得再变为失败（即使后续索引服务故障，本服务也必须以"任务视角"对外负责）。
7. **本服务永远不持有终端用户态**：任何调用方认证 / 权限 / 配额都由上游业务系统负责（Web 管理界面的鉴权由基础设施层负责）。
8. **上传 / 删除不对外**：业务系统不能调用上传 / 删除能力；只能通过 Web 管理界面操作。

## 11. 变更规则

- 若业务范围扩大（新增文档类型、文档语言、新增能力），应**先更新本需求文档**，再驱动规格与实现变更。
- 业务验收口径（§6）和业务不变式（§10）是变更的"硬约束"，不得在未更新本需求文档的情况下被技术实现绕过。
