# 术语表

| 术语 | 含义 |
|------|------|
| 文档（Document） | 一份导入本服务的 PDF / Word / PPT 文件 |
| 文档名（Title） | 文档的业务唯一名称，用于管理与过滤 |
| 文件哈希（File Hash） | 原始文件字节流的 SHA-256 指纹，用于防重复导入 |
| 导入任务（Ingestion Job） | 一次文档受理后异步解析、OCR、建索引的完整过程 |
| 页面（Page） | 文档中的页级锚点 |
| 块（Block） | 页面中连续的文本块 |
| 句子（Sentence） | 教材、讲义类文档中可返回的最小上下文 |
| 题目（Question） | 试卷类文档中可返回的最小上下文 |
| 锚点（Anchor） | 文档内可定位的标识，如页码、块、句、题号 |
| 段落片段（Segment） | 可参与检索的文本单位，通常是句子或题目 |
| 出现记录（Occurrence） | 某个词或短语在具体片段中的命中位置 |
| 精确检索 | 基于倒排索引的单词或短语匹配 |
| 语义召回 | 基于向量相似度的近义表达召回 |
| 混合检索 | 同时组合精确检索与语义召回 |
| 关联文本 | 返回给调用方的句子或题目文本 |
| Web 管理界面 | 本服务自带的文档管理入口 |
| 业务系统 | 调用本服务 gRPC 查询接口的上游后端服务 |
| 硬删除 | 物理删除文档元数据、原始文件、任务记录和索引数据，不可恢复 |
