# 4. 文档存储方案

## 状态

待决定 (Pending)

## 上下文

DocRetrieval 服务需要存储原始文档文件（PDF/Word/PPT），用于：
1. 后续重新解析（如解析器升级）
2. 文档版本管理
3. 管理员查看原始文件

需要评估是复用现有 SeaweedFS 还是使用独立存储方案。

## 决策

**待决定**

选项：
1. **复用 SeaweedFS**（推荐）- 与现有系统保持一致
2. **独立对象存储** - 如 MinIO 或云对象存储

## 备选方案分析

### 方案 A：复用 SeaweedFS
- **优点**：
  - 与现有系统架构一致
  - 运维已熟悉
  - 无需新增组件
- **缺点**：
  - 可能需要调整 bucket/路径策略

### 方案 B：独立对象存储
- **优点**：
  - 完全隔离，不影响现有系统
  - 更灵活的配置
- **缺点**：
  - 新增运维成本
  - 架构不一致
